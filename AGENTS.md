# Обязательные инструкции проекта Handmader

Перед анализом, проектированием или изменением бизнес-логики прочитать полностью [`docs/PRODUCT-SPECIFICATION.md`](docs/PRODUCT-SPECIFICATION.md) и [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

- Спецификация является каноническим источником продуктовых требований.
- Расхождение кода со спецификацией считается дефектом реализации.
- Подтверждённое изменение требования вносится в спецификацию и журнал изменений вместе с кодом.
- Новые доверенные операции реализуются серверными командами внутри модульного монолита.
- Domain-слой не зависит от Next.js, Firebase, React и SDK внешних провайдеров.
- Боевые платежи не подключаются без отдельного решения владельца продукта.
